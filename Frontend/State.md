What is #State ?
literally speaking: it is the "current state" of our program.

### If the interviewer asked, "What is state?", I'd probably answer like this:

>State is a component's internal data that represents information that can change during the lifetime of the component.

What happens when a 
Whenever the state changes, React schedules a re-render, and the UI updates to reflect the new state. We use state for any data that affects what the user sees and that changes due to user interactions, API responses, timers, or other events.
